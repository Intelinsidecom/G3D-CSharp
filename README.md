# G3D-C#

A rewrite of G3D 6.09 Source Code to C# Net Framework 4.

## Features 
 - G3D Core fully ported
 - GLG3D fully ported with OpenGL and DirectX 11 Support
 - All of demos ported and tested

## Why?
Since Roblox Decompilation of 2007 is being almost finished, I was planning porting Roblox to C#. Since G3D is core of rendering, having it ported to see how it performs would be a good comparison of whether Roblox could run on C#
